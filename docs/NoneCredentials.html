Overview

Credentials implementation for infrastructure that requires no cloud authentication, such as Docker or Kubernetes based Coder templates.

The adapter always sends the application credential rich parameters when creating a workspace, and Coder rejects a build if a declared parameter is not supplied, so empty values are returned rather than omitting them.
