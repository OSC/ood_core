Overview

This class is part of a private API. You should avoid using this class if possible, as it may be removed or be changed in the future.

Object used for simplified communication with Flux: runs the flux CLI, locally or over ssh on a submit host, and parses its JSON.

Written in the compact form, like the LSF and SGE adapters' batch.rb, so this file never reopens class Flux. It is required from inside the Flux class body, after the class exists.

def get_jobs(owner: nil)
  args = owner.nil? ? ["-A"] : ["-u", owner.to_s]
  out = call("jobs", "--json", *args)
  parse_jobs(out)
end

def submit_string(str, args: [])
  out = call("batch", *args, stdin: str.to_s)
  OodCore::Job::Adapters::Flux::JobId.to_decimal(out)
